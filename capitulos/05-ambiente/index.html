06 / Preparar o projeto

Comece com uma pasta vazia.

  1. Crie feira-ciencias/ e abra só essa pasta no editor ou agente.
  2. Tenha um navegador e o inspetor à mão. Use a aba Console para erros e o modo responsivo para testar em 360 px.
  3. Se usar Git, guarde um commit quando a primeira versão passar nos testes. Ele será a referência para a próxima mudança.
